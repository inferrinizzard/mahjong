# Algebraic Notation

## Tiles

### Numbered suits

123456789 for man, sou, pin
0 is akadora
ex. 0m12m345m
ex. 1m1s1p

### Characters

1234567 for z (jihai)
1234 are east, south, west, north winds
567 are white, green, red dragons

### Bonus Tiles

12345678 for flowers

## Actions

### Alternative Draw

- C for chi
- P for pon
- K for kan
- A for ankan
- F for bonus

ex. 11mP1m
ex. 2s4sC3s
ex. 4444zA+2s
ex. 4fF+1s

### Win Declarations

- R for riichi
- H for ron
- T for tsumo

ex. 1pR
ex. 3pT

### Turn Syntax Operators

- `> for play tile`
- `_X_ for alternative draw`
- `+ for back wall draw`
- `D for reveal dora`
- `actions before play tile joined by ,`
- `players separated by ' '`

ex. 1s>2p 3p>4z 5m>1s 11sP1s>9s

- East draws 1s, plays 2p
- South draws 3p, plays 4z
- West draws 5m, plays 1s
- North Pon on 1s, plays 9s

ex. 1fF+2s,2222sA+3m,3333mK+4f,4fF+1s>1s 1sH \_ \_

- East draws 1F, declares Flower, draws 2s from back wall, Ankan on 2s, draws 3m from back wall, Kan 3m with existing Pon, draws 4f from back wall, declares Flower, draws 1s from back wall, plays 1s
- South declares Ron on 1s
- West skipped
- North skipped

## Special Rows

### Dora Indicators

- listed after dead wall before first turn
- new row for dora after each kan
